# Glossary — Acronyms Used in This Project

Generated by scanning all docs (`docs/`, `stock_monitor/docs/`) and Python
sources (root + `stock_monitor/`) for uppercase tokens, then verifying each
entry against its actual usage in the code. Ticker symbols (AAPL, MSFT, RF,
SPCX, …) and SQL keywords are omitted — this covers only real acronyms.

## Financial metrics & ratios

| Acronym | Meaning | Where it appears |
|---|---|---|
| ROE | Return on Equity (TTM net income / equity) | `preferred_metrics.py`, `peer_analytics.py`, `fundamentals.parquet` |
| ROIC | Return on Invested Capital (NOPAT / invested capital; banks fall back to NI + interest×(1−t)) | `backfill_edgar.py`, `preferred_metrics.py` |
| NOPAT | Net Operating Profit After Tax (OI×(1−t), or NI + interest×(1−t) for financials) | `backfill_edgar.py` |
| EBITDA | Earnings Before Interest, Taxes, Depreciation & Amortization (OI + D&A; OI-only fallback) | `preferred_metrics.py`, `backfill_edgar.py` |
| EV/EBITDA | Enterprise Value ÷ EBITDA (EV = mktcap + debt − cash) | dual-screen value filters |
| P/B | Price-to-Book (mktcap / equity) | value screens, `dual_screen_analysis.py` |
| D/E | Debt-to-Equity | inclusion rules, `threshold_logic.py` |
| MCA | Market Cap / Assets ratio (MktCap-to-Assets) | `preferred_metrics.py` (`MCA_MAX`), `fundamentals_history.py` |
| EPS | Earnings Per Share | `earnings_calendar.parquet` |

## How this was made

A regex scan (`[A-Z][A-Z0-9]{2,}`) across every `.md` and `.py` file in the
repo (excluding `research/`, `dashboard_data/`, `.git/`, `.venv/`), filtered
against ticker symbols and SQL keywords, then each surviving token was
verified against its source. Re-run `stock_monitor/scan_acronyms.py` to
refresh the candidate list when the codebase changes.
